# EventX

A simple event management web app built with plain HTML, CSS and JavaScript (single file, no build step).

## Features
- Browse events, search by name or city, filter by category
- Create, edit and delete events (Manage / Admin panel with stats)
- Login and signup (demo, stored in the browser)
- Book tickets with a demo payment step (UPI or card)
- My Tickets page with cancel option
- Light and dark theme

## Run locally
Open `index.html` in your browser. That's it.

## Deploy with GitHub Pages
Repo Settings → Pages → Branch: `main` / root → Save.

## Note
Login, payment and data are demo only and stored in `localStorage`. For a real app, add a backend (database, auth, payment gateway).
